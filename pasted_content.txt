1. PESQUISA INICIAL: MÁQUINA SMART 4.0 MODULAR
================================================================================

A "máquina smart 4.0 modular" não é um único produto, mas sim um conceito de
sistemas de manufatura modulares e inteligentes alinhados com os princípios da
Indústria 4.0. Diversas empresas oferecem soluções com este nome ou filosofia,
como a "SMART 4.0" da Exxer ou o "Wittmann 4.0" da WITTMANN Group.

O processo de envio e ditado de dados analisados nesses sistemas segue uma
arquitetura bem definida:

1. CAMADA FÍSICA (Chão de Fábrica)
   - Sensores (temperatura, pressão, posição, status)
   - CLP (Controlador Lógico Programável)
   - Máquina Smart 4.0 Modular
   - Servidor OPC UA embarcado no CLP

2. CAMADA DE REDE (Comunicação)
   - Rede Ethernet (TCP/IP)
   - Protocolos: OPC UA, MQTT, Modbus TCP

3. COLETA DE DADOS (Python)
   - Cliente OPC UA (biblioteca asyncua)
   - Mapeamento de nós (Nodes)
   - Leitura de valores em tempo real

4. ARMAZENAMENTO
   - CSV (histórico)
   - JSON (último dado)
   - Buffer em memória

5. ANÁLISE E IA
   - Análise descritiva
   - Detecção de anomalias (Isolation Forest)
   - Previsão de falhas (Random Forest)

6. VISUALIZAÇÃO
   - Dashboards (Streamlit)
   - Gráficos (Seaborn, Matplotlib, Plotly)

7. COMANDOS E CONTROLE
   - Métodos OPC UA (reiniciar, definir limites)

8. APRESENTAÇÃO (Competição SIC)

4. O QUE É MES?
================================================================================

MES = Manufacturing Execution System (Sistema de Execução de Manufatura)

É o sistema que atua como o "cérebro" do chão de fábrica. Enquanto um ERP cuida
da parte administrativa, o MES monitora, controla e otimiza todos os processos
de produção em tempo real.

As 11 Funções Essenciais (Modelo MESA-11):
1. Gestão de Operações
2. Alocação e Status de Recursos
3. Detalhamento e Sequenciamento da Produção
4. Controle de Documentos
5. Coleta e Aquisição de Dados
6. Gestão de Mão de Obra
7. Gestão da Qualidade
8. Gestão de Processos
9. Manutenção
10. Rastreamento e Genealogia do Produto
11. Análise de Performance

5. DIMENSIONAL MES - DEFINIÇÃO
================================================================================

O Dimensional MES é um sistema de gestão inteligente voltado para a inovação da
nova indústria 4.0. Ele não é apenas um Sistema de Execução de Manufatura (MES)
e sim um "cérebro" que é capaz de integrar, monitorar e orquestrar todo o
ecossistema da célula smart 4.0 modular, um sistema de monitoramento, que é
capaz de transformar dados brutos em tomadas de decisão.

O porquê do Dimensional MES ser um software necessário, é justamente um sistema
capaz de conseguir aprimorar toda cadeia de produção de uma plataforma de
manufatura altamente flexível e versátil, no qual a produção pode ser desde
componentes para o dia a dia até aplicações técnicas de alta precisão.

10. SCRUM ADAPTADO vs SCRUM CONVENCIONAL
================================================================================

Scrum Convencional:
- Framework com regras definidas (Scrum Guide)
- Papéis: Product Owner, Scrum Master, Time de Desenvolvimento
- Eventos: Sprint, Planejamento, Daily, Review, Retrospective
- Artefatos: Product Backlog, Sprint Backlog, Incremento
- Público-alvo: Equipes empresariais

Scrum Adaptado (ou abordagem ágil simplificada):
- Aplicação prática dos princípios ágeis sem rigidez
- Sem papéis formais (desenvolvedor único)
- Eventos simplificados (acompanhamento contínuo)
- Entregas adaptadas ao contexto acadêmico
- Foco em "ser Ágil" e não "fazer Scrum"

CONCLUSÃO: Para um projeto acadêmico individual, o Scrum convencional é
desnecessário. Uma abordagem ágil simples, iterativa e bem documentada é mais
adequada e honesta.

11. FUNDAMENTAÇÃO TEÓRICA (RESUMIDA)
================================================================================

2.1 CONCEITO DE MES
O Sistema de Execução de Manufatura (MES) é uma camada intermediária entre o
planejamento estratégico da empresa e o chão de fábrica. Ele é responsável por
coletar dados em tempo real, monitorar processos, controlar qualidade e garantir
a rastreabilidade da produção, transformando dados brutos em informações úteis
para a tomada de decisão (MCCLELLAN, 2001 apud SANTOS, 2023, p. 22).

2.2 ARQUITETURA DO MES
Na pirâmide da automação industrial, o MES ocupa uma posição central, conectando
os sistemas de gestão empresarial (ERP) ao controle direto das máquinas (CLPs e
SCADA). Esta integração permite que dados do chão de fábrica sejam capturados,
processados e disponibilizados para os níveis superiores (CARVALHO, 2004 apud
SILVA, 2012, p. 12).

2.3 MES E INDÚSTRIA 4.0
Na Indústria 4.0, o MES é um dos pilares fundamentais para a digitalização e
inteligência da manufatura. Sua evolução incorpora tecnologias como IoT,
computação em nuvem, big data e inteligência artificial, ampliando sua
capacidade de coleta, análise e predição (SANTOS, 2023, p. 25).

12. O QUE É UM NÓ (NODE) NO OPC UA?
================================================================================

Um "nó" (node) no contexto do OPC UA é a unidade fundamental de informação que
um servidor, como o do seu CLP, disponibiliza para comunicação e controle.

Tipos de Nós:
- Variable Node: Representa um dado (ex: temperatura, pressão)
- Object Node: Agrupa outros nós (ex: célula Smart 4.0)
- Method Node: Representa uma ação (ex: reiniciar máquina)
- ObjectType / VariableType: Modelos (templates)

Atributos de um Nó:
- NodeId: Identificador único (endereço)
- BrowseName: Nome legível para navegação

Organização:
- Referências (References) conectam os nós
- HasComponent: Liga objeto a variáveis/métodos
- Espaço de Endereços (Address Space): "Biblioteca" de dados

13. O QUE O CLP CONTROLA NA SMART 4.0?
================================================================================

5 Tarefas Principais:

1. CONTROLE DO PROCESSO DE INJEÇÃO
   - Temperatura dos cilindros
   - Velocidade e pressão de injeção
   - Tempo de resfriamento
   - Força de fechamento do molde

2. COORDENAÇÃO DOS ROBÔS E PERIFÉRICOS
   - Comandos para robôs
   - Controle de esteiras
   - Gerenciamento de termorreguladores
   - Ativação de injeção a gás (Airmould)

3. GERENCIAMENTO DE CONJUNTOS DE DADOS DO MOLDE
   - Armazena parâmetros de produção
   - Distribui automaticamente para periféricos
   - Valida compatibilidade

4. EXECUÇÃO DA FUNCIONALIDADE "PLUG & PRODUCE"
   - Identifica novos dispositivos
   - Carrega drivers e parâmetros
   - Configura comunicação OPC UA

5. MONITORAMENTO, RASTREABILIDADE E SEGURANÇA
   - Coleta dados via OPC UA
   - Verifica conformidade
   - Bloqueia operações inseguras
   - Gera alertas

14. STREAMLIT vs SEABORN
================================================================================

SEABORN:
- Biblioteca de visualização estatística
- Propósito: Criar gráficos estatísticos bonitos
- Natureza: Estática (imagem)
- Uso: Análise exploratória, relatórios

STREAMLIT:
- Framework para aplicações web
- Propósito: Criar dashboards interativos
- Natureza: Interativa (aplicação web)
- Uso: Dashboards, ferramentas de ML

COMO TRABALHAM JUNTOS:
- Seaborn cria os gráficos
- Streamlit exibe os gráficos no dashboard
- Integração via st.pyplot()

15. ETAPAS DO DIMENSIONAL MES (RESUMIDO)
================================================================================

CONEXÃO (5 passos)
1. Configurar credenciais (URL, usuário, senha)
2. Criar cliente OPC UA
3. Aplicar autenticação
4. Estabelecer conexão
5. Verificar conectividade

COLETA (5 passos)
1. Mapear nós OPC UA
2. Definir intervalo de coleta
3. Ler valores dos nós
4. Estruturar pacote de dados (timestamp + variáveis)
5. Armazenar (CSV, JSON e memória)

ANÁLISE (5 passos)
1. Carregar dados históricos
2. Calcular estatísticas (média, min, max, desvio)
3. Detectar anomalias (Isolation Forest)
4. Prever falhas (Random Forest)
5. Gerar gráficos (Seaborn)

FLUXO: CONEXÃO → COLETA → ANÁLISE → DASHBOARD (Streamlit)
